# Definition of Ready y Definition of Done

## Definition of Ready

Una HU puede iniciar cuando tiene objetivo, responsable, dependencias, entregable y criterio de aceptacion.

## Definition of Done

Una HU queda terminada cuando:

- El archivo o carpeta comprometida existe.
- El cambio respeta los 8 dominios oficiales.
- No se agrega carpeta `01_ddl/10_configuration`.
- Si es view, materialized view, function, procedure o trigger, queda en archivo individual.
- La documentacion y el tablero se actualizan.
